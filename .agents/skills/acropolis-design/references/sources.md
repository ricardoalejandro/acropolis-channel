# Procedencia revisada

La skill del proyecto es una adaptación escrita para Acrópolis; no instala ni ejecuta utilidades externas. Las referencias se fijan a commits para que una actualización remota no cambie instrucciones silenciosamente.

- Impeccable 4.5.0, pbakaus/impeccable, Apache-2.0: https://github.com/pbakaus/impeccable/tree/f676fb4ff08eeed1e422d9869d08618819e29549. Se tomaron como guía la distinción entre superficies de descubrimiento, lectura y operación; contexto antes de editar y revisión visual acotada. No se copia su launcher ni su detector.
- Vercel Web Interface Guidelines, MIT: https://github.com/vercel-labs/web-interface-guidelines/blob/434b7f91364665f2f733b310ec54809bf8f37937/command.md. Guía para semántica, foco, formularios, navegación, movimiento, contenido largo y eficiencia. Sus preferencias de copy inglesas no sustituyen el español del producto.
- Agent Skills de Vercel, web-design-guidelines 1.0.0, referencia de descubrimiento: https://github.com/vercel-labs/agent-skills/tree/063bee94c3f4df8453406c830b0a7df0f2860278/skills/web-design-guidelines.

No se redistribuye código de esos proyectos. Los assets y sus licencias se documentan en frontend cuando se incorporan. Revisar cambios de versión antes de actualizar estos enlaces.
